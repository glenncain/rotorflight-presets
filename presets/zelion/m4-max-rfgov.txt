#$ AUTHOR: glenncain
#$ DESCRIPTION: The entire OMP M4 Max configuration in one preset: every master setting, all
#$ DESCRIPTION: three PID profiles, and all three rate profiles.
#$ DESCRIPTION: Applying this restores the helicopter in one action, the way pasting a diff
#$ DESCRIPTION: into the CLI would.
#$ DESCRIPTION: It carries its own "profile N" and "rateprofile N" selectors, so each tune
#$ DESCRIPTION: lands in its intended slot no matter which profile is active when you apply
#$ DESCRIPTION: it. It leaves the flight controller on profile 1 and rate profile 1.
#$ DESCRIPTION: Headspeeds are 1850, 2400 and 2750 rpm on profiles 1 to 3, using Rotorflight's
#$ DESCRIPTION: own ELECTRIC governor rather than the ESC's. AUX3 moves PID profile and rate
#$ DESCRIPTION: profile together, so one switch gives all three setups with matching rates.
#$ DESCRIPTION: Rates are RACEFLIGHT type throughout, identical stick rates with progressively
#$ DESCRIPTION: harder setpoint boost; rate profile 3 also trims collective rate to 52.
#$ DESCRIPTION: Contains no "save". Use the Configurator's Save button after reviewing.
#$ DESCRIPTION:
#$ DESCRIPTION: Three things here are specific to this helicopter and this transmitter.
#$ DESCRIPTION: On any other machine, delete them before applying:
#$ DESCRIPTION:   - "set name", "set model_id = 28" and "set model_set_name" under
#$ DESCRIPTION:     "Craft name and model match". Model id 28 is this transmitter's
#$ DESCRIPTION:     model-match number; another heli would answer to the wrong model memory.
#$ DESCRIPTION:   - The servo and mixer lines under "Swashplate and servos", which describe
#$ DESCRIPTION:     this airframe's linkages, horns and grips.
#$ DESCRIPTION:   - "set debug_mode" and "set debug_axis", a gyro-trace tuning aid rather
#$ DESCRIPTION:     than configuration.
#$ PRIORITY: 0
#$ WARNING: Whole-helicopter restore, not a tweak: this overwrites PID profiles 1-3, rate profiles 1-3 and the master configuration. Take a "diff all" backup first. Servo centres, travel and swashplate geometry are specific to this airframe, and craft name and model id 28 are specific to this transmitter - read the description before applying this to any other helicopter. Bench-test the governor and check the swash with blades off before flying.
